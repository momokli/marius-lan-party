# 🧟 Left 4 Dead 2 — Status: NICHT auf Apple Silicon lauffähig

**Kurzfazit:** Der L4D2-Dedicated-Server (srcds) ist ein **32-bit-Binary** — Valve hat trotz
jahrelanger Community-Forderungen kein 64-bit-Update veröffentlicht
(z.B. <https://www.reddit.com/r/l4d2/comments/1grw9tv/valve_please_give_us_an_64bit_update_as_part_of/>,
Stand 2025). **Rosetta 2 emuliert nur x86_64, kein 32-bit** → der Container läuft auf dem
M4-Mac **nicht** (weder Docker-Desktop-Rosetta noch QEMU-Helfer helfen zuverlässig;
auch unter box86/ARM-Linux-Emulation scheitert er, siehe
<https://github.com/ptitSeb/box86-compatibility-list/issues/125>).

## Empfehlung für die Party

**Listen-Server statt Dedicated:** Bei 4 Leuten reicht ein normaler Host aus der Spieler-Session
(im Spiel → Hauptmenü → „Host") — GAMES.md sagt ohnehin „Host reicht". Kein Dedicated-Server nötig.

Das Compose-File `docker-compose.l4d2.yml` ist trotzdem im Stack, **nur für x86_64-Hosts**
(Intel-Mac, Windows/Linux-PC als Fallback-Server bei der Party):

```bash
docker compose -f docker-compose.l4d2.yml up -d
```

## Settings (falls x86_64-Host)

Basis: Image `ghcr.io/jackzmc/srcds-l4d2` (komplette Server-Files, kein SteamCMD-Update nötig;
<https://github.com/Jackzmc/docker-l4d2-server>). Alle Einstellungen als `command`-Args:

| Arg | Empfehlung | Begründung |
|---|---|---|
| `+map c1m1_hotel` | Kampagnen-Start | erste Map (Dead Center); andere Kampagnen: `c2m1_highway`, `c5m1_waterfront` … |
| `+maxplayers 4` | 4 | genau wir |
| `+sv_lan 1` | LAN | keine Internet-Clients |
| `+hostname "LAN-Party L4D2"` | — | sichtbar im Server-Browser |
| `+sv_password "…"` | optional | LAN: eher unnötig |
| `-usercon` | ✅ | RCON-Konsole |
| `-nowatchdog` | automatisch (Image) | verhindert SIGALRM-Crashes (Image-README) |

**Gamemodes:** `coop` (Standard), `versus`, `survival`, `realism` — z.B.
`+map c8m1_apartment versus +sv_gametypes VERSUS` (Image-README).

Addons/SourceMod: nach `data/l4d2/addons/` legen (mountet auf `/server/left4dead2/addons`).

**RAM:** 2–4 GB. **Ports:** 27015/tcp+udp. **Disk:** ~13 GB (im Image enthalten).
